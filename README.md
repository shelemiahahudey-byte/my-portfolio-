# Shelemiah Ahudey Portfolio

A polished, recruiter-focused static portfolio built with HTML, CSS and JavaScript.

## Included
- Live links to JeskyNet Store and Family Connect Cloud
- Strong hero section designed to communicate value quickly
- Selected-work case study cards
- Dedicated project showcase video section
- About, skills, "Why me", and contact sections
- Responsive mobile/desktop layout
- No build step required

## Add your video
Create this folder if needed:

`media/`

Then place your video here:

`media/showcase-video.mp4`

Open `index.html` in a browser to test.

## Personalization before sending to employers
Replace or add:
- LinkedIn profile URL
- GitHub profile URL
- CV/resume download link
- Phone/WhatsApp if you want it displayed
- Actual project screenshots if you want image-based previews

## Deployment
This can be hosted directly on Netlify, Vercel, GitHub Pages or another static hosting provider.
